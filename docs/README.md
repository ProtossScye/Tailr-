# Tailr V1 — Project Pack

Tailr is a personalized betting-slip assistant with manual bet tracking and a performance dashboard. This folder is the shared brief for you, your friend, and your Codex/Claude workflow.

## V1 promise
Bring Tailr a slip. Tailr helps you understand it, adapt it to your preferences, and keep a clear record of bets you choose to place.

## Product pillars
1. Slip assistant: text/image input, structured extraction, user review, preference-aware suggestions.
2. Manual tracker: users separately record bets they actually placed.
3. Performance dashboard: settled P/L, stake, ROI, win rate, pending bets, and history.
4. One product backend with multiple interfaces: web first, Telegram next, X only after checking API access, terms, and cost.

## Boundaries
V1 does not place bets, handle money, or log into sportsbook accounts. No sportsbook passwords/OTPs. No automatic history syncing. User-reported results are not independently verified. Never invent odds, markets, booking codes, or sportsbook capabilities.
